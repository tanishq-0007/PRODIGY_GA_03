# Shakespeare Text Generation using Markov Chains

This project generates Shakespeare-style sentences using Markov Chains, SpaCy, and NLTK.

The model is trained using text from:

- Hamlet
- Macbeth
- Julius Caesar

## Technologies Used

- Python
- SpaCy
- NLTK
- Markovify

## What This Project Does
Loads Shakespeare plays from NLTK Gutenberg dataset
Cleans and processes the text
Generates random Shakespeare-style sentences
Uses POS-based text generation for better sentence structure

## Features
Text cleaning and preprocessing
Sentence generation using Markov Chains
POS-tag based sentence generation
Short sentence generation
